# Glossary

- **Task** — one item on your list, with a title and an open/done status.
- **Priority** — low, medium, or high; affects list order.
- **Due date** — optional calendar date; open tasks past it show as OVERDUE.
- **Tag** — optional lowercase label used to filter `todo list --tag`.
- **Sync** — upload your task list to the cloud for backup.
